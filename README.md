# 🛒 Blinkit Clone

A responsive frontend clone of the popular instant-delivery platform **Blinkit**, built with React. This application replicates key user flows including product browsing, category navigation, responsive layout design, and a modern shopping UI.

---

## 🚀 Features

- **Responsive Design:** Optimized for mobile, tablet, and desktop viewports.
- **Category Navigation:** Browse through grocery, daily essentials, snacks, and beverages.
- **Product Catalog:** Clean card layouts displaying prices, unit sizes, and add-to-cart actions.
- **Modern UI Components:** Mimics the branding, color schemes, and layout conventions of Blinkit.

---

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Styling:** CSS3 / Tailwind CSS *(update based on your styling tool)*
- **Icons:** React Icons / Lucide React *(update if used)*
- **Tooling:** Vite / Create React App

## 💻 Getting Started Locally

Follow these steps to run the application on your local machine:

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) installed:

**node -v
npm -v**

### 2. Clone the Repository
```bash
git clone https://github.com/prity/blinkit-clone.git
cd blinkit-clone
```

### 3. Install Dependencies

**npm install**

### 4. Run the Development Server

npm run dev
*(or "_npm start_" depending on setup)*

Open [http://localhost:5173](http://localhost:5173) (or `http://localhost:3000`) in your browser.
